# StaySync – Hotel Housekeeping Coordination System

**StaySync** is a web-based hotel housekeeping management system designed for **The Meridian Grand Hotel**. It helps hotel administrators and housekeeping staff coordinate room cleaning, manage room availability, assign tasks, and monitor daily hotel operations through a centralized dashboard.

🌐 **Live Website:** https://staysync.pr7tik.workers.dev/

## ✨ Features

- **Dashboard** – Overview of hotel rooms, occupancy, cleaning progress, and operations.
- **Room Management** – Monitor room availability, occupancy, and cleaning status.
- **Housekeeping Tasks** – Assign, track, and manage room-cleaning tasks.
- **Staff Management** – Manage housekeeping staff and assignments.
- **Room Inspections** – Track room inspections and cleanliness.
- **Maintenance Requests** – Manage room maintenance issues.
- **Notifications** – Stay updated with operational activities.
- **Reports & Analytics** – View housekeeping performance and statistics.
- **Responsive UI** – Clean interface designed for desktop and mobile devices.

## 🚀 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/pr7tik/StaySync.git
   ```

2. Open the project folder:

   ```bash
   cd StaySync
   ```

3. Open `index.html` in your browser.

   Alternatively, use the VS Code Live Server extension.

## 💾 Data Storage

StaySync uses JavaScript-based local demo data without requiring an external database or services such as Supabase.

The demo environment is intended for demonstration and educational purposes.
